# DemoBlaze – Manual & Automation Testing Project

---

## Project Overview

DemoBlaze is a demo e-commerce web application tested using **Manual Testing and Selenium Automation Testing**.

The project focuses on validating core e-commerce functionalities including:

* User Registration
* User Login
* Logout
* Home Page
* About Us
* Contact
* Product Categories
* Product Details
* Shopping Cart
* Place Order / Checkout

## Automation Framework

The automation framework is developed using:

**Java + Selenium WebDriver + TestNG + Maven + Page Object Model**

The Page Object Model approach is used to separate page elements and page actions from test cases, improving code reusability, readability and maintainability.

### Framework Structure

```text
DemoBlaze
│
├── src
│   ├── main
│   │   └── java
│   │       ├── base
│   │       ├── pages
│   │       └── utilities
│   │
│   └── test
│       └── java
│           └── tests
│
├── test-output
├── testng.xml
├── pom.xml
```
